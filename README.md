Welcome! This is our repository for scripts to generate results for our article:
"Gusto: a toolkit for compatible finite element dynamical cores."

The results here were generated with:
- Firedrake version 
- Gusto main at the commit 2348df5295b1e8806e76d992c811cc9155bcd23f

To install Firedrake and Gusto, please follow the instructions on
https://github.com/firedrakeproject/gusto

The results are generated with the scripts in the `test_scripts` directory.
The makefile contains commands with the exact configurations used in the paper.

Plots are generated with the scripts in the `plotting_scripts` directory. This
requires an installation of tomplot: https://github.com/tommbendall/tomplot
